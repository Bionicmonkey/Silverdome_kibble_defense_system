Silverdome — How It Works

The full detection pipeline: from webcam frame to consensus-driven arm actuation, step by step.

Step 1 — Capture

📷 Webcam Frame Every Second

The webcam opens once via DirectShow and captures a live frame every ~1 second. Each frame is saved as temp.jpg in the working directory — a shared file read by MonitorAppweb for the live dashboard snapshot.

Step 2 — Motion Gate

Difference Check (Diff-Gate)

Before calling the AI model, the system compares the current frame against the last "no animal" baseline using pixel-level RGB delta. Only when enough pixels change beyond a threshold (~10%) does it proceed to inference — saving Ollama calls when the scene is static.

Step 3 — Vision Inference

qwen2.5vl Fine-Tuned Model Analysis

The frame is resized, base64-encoded, and sent to a local Ollama instance running a fine-tuned qwen2.5vl vision model. The model receives the image plus a structured system prompt asking it to identify any animals on the porch.

Step 4 — Consensus Loop

🛡️ Anti-Spam Protection (Consensus Buffer)

A single "bad animal" detection does not close the gate — one glitch or false positive is not enough to spook a legitimate cat visitor. The system maintains a rolling vote buffer and requires accumulating 3 consecutive bad-animal votes before committing to arm closure.

Step 5 — Decision Gate

Confidence Threshold Check

When the buffer reaches 3 consecutive bad-animal votes (equivalent to ~3 seconds of sustained detection), a confirmation event is triggered. If good-animal votes appear before that threshold, the counter resets — protecting legitimate visitors from false closures.

Step 6 — Arm Closure

🔒 Actuator Command (ticcmd → Pololu TIC500)

Confirmed bad-animal triggers a sequence: energize motor, drive to closed position, wait 15 seconds for mechanical settling, then de-energize. The arm state is persisted to state.txt and an alarm sound plays.

Step 7 — Closure Hold & Release

🔑 Double-Guard Release Policy

The gate stays closed even after the animal leaves. It will only reopen when both conditions are met simultaneously: (1) no bad-animal detected for 3 consecutive loops (~3 seconds), AND (2) at least 60 seconds have passed since the last bad-animal detection. This prevents rapid close-open-close cycling when an animal lingers.

⏱ Timing

Webcam captures every ~1 second. Diff-gate skips Ollama when scene is static. Forced fresh check runs every 30 seconds regardless of diff score.

🛡️ False-Positive Protection

A single bad detection never closes the gate. Consensus requires 3 consecutive "bad" votes (~3 seconds) before any arm action is triggered.

🔒 Stay-Closed Policy

After closure, the gate holds for a minimum of 60 seconds AND requires 3 consecutive clear frames. Prevents an animal from "testing" the gate repeatedly.

🤖 AI Model

A fine-tuned qwen2.5vl vision model running locally via Ollama, receiving base64-encoded frames plus a structured classification prompt.
